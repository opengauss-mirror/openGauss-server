# 原子任务实施清单

本清单由任务目录生成；设计是唯一语义依据。初始所有任务均为 pending，不代表任何功能通过。步骤中的实测由后续实施执行，本次生成执行包未运行数据库。

Q-01 与 V-01/V-02 按阶段拆分；Q-01-D1/D2/D3 先定义本阶段工作量估计。F-00 和 F-09-D 只属于第三阶段，不阻塞前两阶段。一个任务完成后继续其依赖已经满足的任务。
